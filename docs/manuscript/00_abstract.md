# Abstract

AgenticMesh defines an asynchronous tool interface with explicit parameter,
return-value, and descriptive metadata. A trusted-input arithmetic example
demonstrates the call contract. A separate worked example alternates belief
updates and categorical actions in a local discrete partially observable
Markov decision process. We describe the implemented score and policy update,
then report a controlled first-observation check and inspect an archived
simulation. This evidence concerns the software contract and the behavior of
the synthetic model.
