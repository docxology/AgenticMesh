# AgenticMesh manuscript

The ordered sections describe the tool interface, the synthetic model, its
checked initial calculation, and the archived diagnostic evidence.
`config.yaml`, `preamble.md`, and `references.bib` supply the render
configuration and citations.

Follow [local verification and the pinned render](../verification.md) to stage
the [historical log](../../active-inference/logs/active_inference_demo_20250129_165711.json)
and [belief plot](../../active-inference/visualizations/run_20250129_165717/belief_evolution.png).
The staging script copies the plot and records its checksum and evidence path.
The PDF and web outputs are derived locally.
